# 🎂 Code Birthday VR — Đặng Thành Đạt

Website sinh nhật 3D dành cho **em Đặng Thành Đạt** với phong cách công nghệ **xanh teal – xanh mint**, dựng từ cấu trúc Birthday VR V3.

## 🌐 View Demo

**[XEM BẢN SINH NHẬT ĐẶNG THÀNH ĐẠT](https://hachngochai.github.io/DatCode_Birthday/)**

> Nếu link chưa hiển thị, vào **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save** rồi đợi GitHub Pages hoàn tất.

## ✨ Tính năng

- Mô hình sinh nhật Three.js với đảo 3D, nhân vật, hộp quà và bánh sinh nhật chủ đề xanh công nghệ.
- Hai bảng mã trang trí nổi 3D, animation nhẹ gợi ý đam mê lập trình.
- Nút **☀ NGÀY / ☾ ĐÊM**, điều khiển chuột/chạm trên điện thoại.
- Mở quà → khám phá → cắm **5 cây nến** → bật micro thổi nến (có tùy chọn thay thế) → nghe Happy Birthday → nhận và mở lá thư **Gửi em Đạt**.
- Font tiếng Việt Noto Serif; hỗ trợ màn hình mobile; WebXR nếu trình duyệt và thiết bị hỗ trợ.

## Chạy tại máy

```bash
python -m http.server 5500
```

Mở http://localhost:5500/ và đảm bảo có mạng để tải Three.js.
